# 14 天前端开发实践任务：个人博客网站

## 一、任务目标

在 14 天内，完成一个个人博客网站。

你目前只需要具备 C 语言基础。本次任务希望你通过实践，初步掌握 HTML、CSS 和 JavaScript，并最终做出一个能够正常使用的博客网站。

**本次任务主要关注 JavaScript 的逻辑实现。** HTML 和 CSS 不作严格要求，不需要追求专业的页面设计，只要布局基本合理、页面能够正常使用即可。

不要求使用 React、Vue、Node.js 等框架，只使用 HTML、CSS 和原生 JavaScript 完成项目。

## 二、项目功能要求

开发一个用于展示个人文章、学习笔记或技术心得的博客网站，需要实现以下功能：

1. **文章列表：** 首页展示多篇文章，包括标题、摘要、发布时间和分类。
2. **文章详情：** 点击文章后，可以查看对应的完整内容。
3. **文章搜索：** 支持通过关键词搜索文章标题，并展示匹配结果。
4. **分类筛选：** 可以按照文章分类筛选内容，例如 C 语言、JavaScript、学习笔记等。
5. **新增文章：** 通过表单填写标题、摘要、正文和分类，发布新文章。
6. **编辑文章：** 可以修改已有文章的内容。
7. **删除文章：** 可以删除文章，删除前需要进行确认。
8. **数据保存：** 使用浏览器的 \`localStorage\` 保存文章数据，刷新页面后，新增、编辑和删除的结果仍然存在。
9. **基本页面适配：** 网站在电脑和手机浏览器中都能正常浏览和操作。

初始数据至少包含 5 篇文章，文章内容可以自行编写。

## 三、技术要求

### HTML 和 CSS

能够使用 HTML 搭建页面，使用 CSS 完成基本的布局、间距和颜色设置即可。不要求深入掌握复杂的页面设计技巧。

### JavaScript（重点）

项目开发过程中，需要重点学习和实践以下内容：

- **基础语法：** 变量、数据类型、条件判断、循环和函数。
- **数组与对象：** 使用数组保存文章列表，使用对象描述单篇文章。
- **数组操作：** 学习 \`map()\`、\`filter()\`、\`find()\` 等常用方法。
- **DOM 操作：** 使用 JavaScript 获取、创建和修改页面元素。
- **事件处理：** 处理按钮点击、输入框变化和表单提交等事件。
- **动态渲染：** 根据文章数据动态生成列表和搜索结果。
- **数据增删改查：** 使用 JavaScript 实现文章的新增、查看、修改和删除。
- **本地存储：** 使用 \`localStorage\` 和 JSON 保存、读取文章数据。
- **代码组织：** 将不同功能拆分成合理的函数，让代码易于理解和维护。

## 四、开发要求

1. 所有核心功能都需要真正实现，不能只有页面样式而没有实际交互。
2. 文章列表、搜索结果和分类筛选结果必须根据 JavaScript 数据动态生成。
3. 新增、编辑和删除文章后，页面显示与本地存储的数据必须保持一致。
4. 对空标题、空正文、无搜索结果等情况进行基本处理。
5. 提交完整的 HTML、CSS、JavaScript 源代码。
6. 可以根据自己的想法设计博客的风格和页面布局。

**特别鼓励使用 AI 学习和开发！**

你可以使用 ChatGPT、豆包、Claude、Cursor 或其他 AI 工具来学习知识、生成网页、优化样式、编写代码和排查错误。

不要求所有代码都亲手从零编写。更重要的是，借助 AI 完成项目的同时，逐步理解 JavaScript 的运行逻辑，知道代码为什么这样写，以及出现问题时应该如何定位。

## 五、学习路线与参考资料

不需要一开始就把所有知识学完再开始做项目。建议一边学习，一边动手实践，遇到不会的内容再针对性地补充。

### 第一阶段：学习 HTML 和 CSS（第 1–3 天）

学习目标：能够看懂网页的基本结构，并完成博客的初始页面。

参考视频：[HTML + CSS 入门教程（Bilibili）](https://www.bilibili.com/video/BV1MvaVzUEuz/)

建议重点学习：

- HTML 常见标签、链接、图片和表单。
- CSS 选择器、颜色、字体、间距和盒模型。
- Flexbox 等基本布局方式。
- 如何将 HTML、CSS 和 JavaScript 文件组织在一起。

**学习建议：** 视频不需要每一段都跟着敲代码。先看懂老师在讲什么，理解标签、样式和布局分别有什么作用，再结合自己的博客项目实践即可。遇到不理解的地方，可以直接向 AI 提问。

### 第二阶段：学习 JavaScript（第 4–9 天）

学习目标：掌握博客项目需要的 JavaScript 基础，能够使用代码处理文章数据和网页交互。

参考视频：[JavaScript 入门教程（Bilibili）](https://www.bilibili.com/video/BV1Y84y1L7Nn/)

建议重点学习：

- 变量、数据类型、条件判断、循环和函数。
- 数组、对象及常用数组方法。
- DOM 操作和事件监听。
- 表单处理和数据渲染。
- \`localStorage\` 与 JSON 数据存储。

**学习建议：** 这部分是整个项目的重点。可以先理解视频中的概念和示例，不必机械地把所有代码抄一遍。学完一个知识点后，尝试让 AI 结合博客项目举例，再自己动手修改、运行和验证。

例如，学完数组和对象后，就尝试用数组保存 5 篇文章；学完 \`filter()\` 后，就尝试实现文章搜索；学完 \`localStorage\` 后，就尝试保存新增的文章。

### 第三阶段：结合项目实践（第 10–14 天）

学习目标：把前面学到的知识组合起来，完成博客的核心功能。

- 第 10 天：完成文章新增。
- 第 11 天：完成文章编辑和删除。
- 第 12 天：完成数据保存、搜索和分类筛选的整体联调。
- 第 13 天：修复问题，优化页面和代码。
- 第 14 天：检查项目、整理源代码并提交。

以上是建议安排，可以根据实际学习情况调整，但需要在 14 天内完成整个项目。
